# GNSS-SPP-Pipeline: 模块化全链路全自动单点定位与 AI 纠偏系统

一个基于 Python 与 PyQt6 构建的工业级单点定位（SPP）全链路全自动解算系统。本系统能够自适应解析标准 RINEX（观测文件与广播星历文件），内置高斯-牛顿迭代交会算子，并提供传统高精多通道分离渲染与边缘 AI（线性回归/随机森林）误差自适应预测补偿的两种完全体解决方案。

---

## 📂 项目模块架构

项目目前由两个核心系统文件组成，满足不同阶段的学术实验与工程解算需求：

| 核心文件名称                     | 定位底盘算子                            | 核心渲染与输出亮点                                           |
| :------------------------------- | :-------------------------------------- | :----------------------------------------------------------- |
| **`gnss_spp_main_system.py`**    | 传统高斯-牛顿单点定位交会矩阵           | **三轴高精时序完全解耦**：将东向 (East)、北向 (North)、天向 (Up) 的偏差彻底剥离为独立的镜面时序收敛曲线，提供深度透视 3D Error。 |
| **`gnss_spp_main_system_ai.py`** | 传统解算底盘 + **边缘 AI 动态纠偏引擎** | **AI 赋能与学术级指标对比**：支持选择 **随机森林** 或 **线性回归** 策略，动态提取卫星数、PDOP 等特征，对物理层残余延迟实施实时修正，输出学术级补偿前后对比曲线与高精报表。 |

---

## 🚀 核心技术与算法亮点

### 1. 传统物理定位底盘 (`gnss_spp_main_system.py`)
* **通用自适应 RINEX 解析引擎**：支持流式文本安全扫描，兼容多版本历元识别与断句（包括 `.cmb`、`.rnx`、`.26o` 等格式），自动提取头文件中的近似坐标（`APPROX POSITION XYZ`）。
* **时序完全隔离渲染**：利用 Matplotlib 多画布物理剥离技术，将复杂的 ENU（东-北-天）三维误差完全去耦，杜绝多轴文本重叠。
* **高安全性后台算子**：计算逻辑完全封装在独立线程 `QThread` 中，向主线程投递纯 native 数据类型（`list`, `dict`），切断跨线程共享 C++ 复杂指针的可能，**彻底防御 `0xC0000409` 闪退崩溃**。

### 2. 边缘 AI 误差预测与自适应补偿引擎 (`gnss_spp_main_system_ai.py`)
* **学术级特征工程**：自动构建以历元卫星数（`Sat_Count`）、几何精度因子（`PDOP`）为交叉特征的场景矩阵。
* **数据闭环流机制**：采用 $70\%$ 历史场景训练集拟合调优，$30\%$ 测试集评估，实时拦截并扣除未修正干净的对流层/电离层等系统性空间残余几何延迟。
* **智能成果命名公式**：成果落盘时，文件名将完美融合 **【输入测站源 + AI策略标签 + 实时时间戳】**（例如：`gnss_ai_compensated_bjfs1500_RandomForest_20260704_001200.csv`），便于批量自动化多方案对比。

## 🛠️ 环境依赖与安装

本项目运行于 Python 3.10+ 环境。请在终端执行以下命令安装核心依赖库：

```bash
pip install PyQt6 numpy pandas matplotlib scikit-learn
```
